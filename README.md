## 📖 Overview

CampusCart is a full-stack web application developed to simplify buying and selling within a college campus. The platform provides students with a secure and user-friendly environment to list products, browse available items, manage their listings, and connect with other users.

In addition to marketplace functionality, the application also includes a **Lost & Found** module to help students report and recover misplaced belongings.

# ⚙️ Installation

## Clone the repository

```bash
git clone https://github.com/sona-vs/Campuscart.git
```

## Navigate to the project

```bash
cd Campuscart
```

## Install dependencies

```bash
npm install
```

## Start the application

```bash
npm start
```
