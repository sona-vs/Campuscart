## 📖 Overview

CampusCart is a full-stack web application developed to simplify buying and selling within a college campus. The platform provides students with a secure and user-friendly environment to list products, browse available items, manage their listings, and connect with other users.

In addition to marketplace functionality, the application also includes a **Lost & Found** module to help students report and recover misplaced belongings.

---

## ✨ Features

### 👤 User Management
- Secure user authentication
- User profile management
- Personalized dashboard

### 🛍️ Marketplace
- Browse available products
- Create product listings
- Manage personal listings
- View detailed product information

### 📦 Selling
- List products for sale
- Update or remove listings
- Track your posted items

### 🔍 Lost & Found
- Report lost items
- Publish found items
- Help students recover belongings

### 🔔 Notifications
- Stay updated with important activities
- Receive marketplace notifications

### 📱 Responsive Design
- Optimized interface for desktop and mobile devices

# ⚙️ Installation

## Clone the repository

```bash
git clone https://github.com/sona-vs/Campuscart.git
```

## Navigate to the project

```bash
cd Campuscart
```

## Install dependencies

```bash
npm install
```

## Start the application

```bash
npm start
```

The application will be available at:

```text
http://localhost:4200/
```
